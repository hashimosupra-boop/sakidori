# 【日本市場版】「サキドリ」実行計画：詳細ロードマップ

**作成日:** 2026年3月17日
**作成者:** Manus AI

## はじめに

本ドキュメントは、先日提出した「【日本市場版】サキドリ多角的分析レポート」に基づき、日本市場での成功に向けた実行計画を詳細に定義するものです。4つのフェーズ（集客基盤構築、MVP開発、ローンチと検証、改善と拡大）について、具体的なタスク、週単位のスケジュール、担当領域、そして成功指標（KPI）を日本市場に合わせて最適化しました。

## 全体像：4フェーズ・24週間の計画

プロジェクトは、最初の約6ヶ月（24週間）を重要なマイルストーンと位置付け、以下の4つのフェーズを並行または連続して実行します。

| フェーズ | 期間 | 主な目的 |
| :--- | :--- | :--- |
| **Phase 1: 集客基盤構築** | 1〜12週目 | アプリローンチ前に見込み顧客のオーディエンスを構築し、初速を最大化する。 |
| **Phase 2: MVP開発** | 1〜12週目 | コア仮説を検証するための、日本市場に最適化されたMVPを迅速に開発する。 |
| **Phase 3: ローンチと検証** | 13〜16週目 | 日本市場にプロダクトを投入し、初期ユーザーの反応と主要指標を測定・分析する。 |
| **Phase 4: 改善と拡大** | 17週目以降 | データとフィードバックに基づき、プロダクトとマーケティングを継続的に改善・拡大する。 |

---

## Phase 1: 集客基盤構築 (1〜12週目)

**目的:** アプリのローンチに先立ち、日本のターゲット顧客との接点を確立し、期待感を醸成する。
**担当領域:** マーケティング
**成功指標(KPI):**
*   SNSフォロワー合計 (X, Instagram, TikTok): 5,000人以上
*   LINE公式アカウント友だち数: 500人以上
*   noteのフォロワー数: 500人以上

| 週 | 主要タスク | 具体的なアクション | 完了成果物 |
| :--- | :--- | :--- | :--- |
| **1-2** | **戦略策定と準備** | ・ターゲット（学生、20-30代社会人）のSNS利用動向を分析<br>・**X, Instagram, TikTok, note**のアカウント開設<br>・3ヶ月分のコンテンツカレンダーを作成 | ・競合分析レポート<br>・コンテンツカレンダー |
| **3-8** | **コンテンツ制作と投稿** | ・「#先延ばしあるある」等のショート動画を週3本制作（TikTok/Instagramリール）<br>・Xで共感を呼ぶポストを1日2回以上投稿<br>・**noteで開発秘話や心理学に関する考察記事を週1本執筆** | ・ショート動画 18本<br>・note記事 6本 |
| **5-8** | **LPとリストビルディング** | ・アプリのティザーLPを作成<br>・「先行アクセス権」をインセンティブに**LINE公式アカウント**への登録を促進<br>・登録者向けに週1回、開発進捗や限定コンテンツを配信 | ・公開済みティザーLP<br>・LINE公式アカウント設定 |
| **9-12** | **エンゲージメント強化** | ・コメントやDMへの24時間以内の返信体制を構築<br>・Xでアンケートやスペース機能を活用した企画を実施<br>・国内の生産性・自己啓発系インフルエンサーへのアプローチを開始 | ・エンゲージメントレポート<br>・インフルエンサーリスト |

## Phase 2: MVP開発 (1〜12週目)

**目的:** 「AIコーチの（日本文化に合った）説得がユーザーの行動を変えるか」というコア仮説を検証するMVPを開発する。
**担当領域:** 開発、デザイン
**成功指標(KPI):**
*   12週目までにTestFlight/クローズドベータ版をリリース
*   主要機能が仕様通りに動作し、**AIの応答が日本の文化・言語のニュアンスに合致している**
*   バグ発生率がクリティカルレベル以下

| 週 | 主要タスク | 具体的なアクション | 完了成果物 |
| :--- | :--- | :--- | :--- |
| **1-2** | **要件定義と設計** | ・MVPの3機能（オンボーディング、AIチャット、ストリーク記録）の詳細仕様を策定<br>・**AIコーチのペルソナ（優しいサポーター型等）と応答シナリオを日本向けに設計**<br>・技術スタックとDB/API仕様を設計 | ・詳細仕様書<br>・AIペルソナ設計書 |
| **3-4** | **UI/UXデザイン** | ・FigmaでUIデザインを作成<br>・**日本語フォントの選定**とレイアウト調整<br>・プロトタイプでユーザビリティテストを実施 | ・Figmaデザインファイル<br>・プロトタイプ |
| **5-10** | **実装** | ・React NativeでUIコンポーネントを実装<br>・SupabaseでDBと認証機能を構築<br>・Groq APIを連携し、**日本向けに調整したプロンプト**でAIコーチを実装 | ・GitHubリポジトリ<br>・動作するコンポーネント |
| **11-12** | **テストとデプロイ** | ・単体テストと結合テストを実施<br>・Phase1で集めたリストからテスターを募集し、クローズドベータテストを開始<br>・App Store / Google Playへの申請準備（**日本のプライバシーポリシー基準**を確認） | ・テスト仕様書<br>・TestFlight/ベータ版ビルド |

## Phase 3: ローンチと検証 (13〜16週目)

**目的:** プロダクトを日本市場に投入し、初期ユーザーの反応を測定。PMF（プロダクトマーケットフィット）の兆候を探る。
**担当領域:** 全員
**成功指標(KPI):**
*   ダウンロード数: 1,000件以上
*   有料会員転換率 (CVR): 5%以上
*   Day7リテンション率: 20%以上

| 週 | 主要タスク | 具体的なアクション | 完了成果物 |
| :--- | :--- | :--- | :--- |
| **13** | **プレローンチ** | ・ベータテスターからのフィードバックに基づき、バグやUIの違和感を修正<br>・SNSとLINE公式アカウントでローンチ日を予告 | ・修正済みビルド<br>・ローンチ告知投稿 |
| **14** | **正式ローンチ** | ・App Store / Google Playでアプリを公開<br>・**note、Qiita、PR TIMESでプレスリリースを配信**<br>・構築済みのオーディエンスに一斉告知<br>・アプリレビューメディアへの掲載を依頼 | ・各ストアの公開ページ<br>・プレスリリース |
| **15-16** | **データ分析と検証** | ・各種KPIをダッシュボードで定点観測<br>・**価格（980円/月、5,980円/年）**とトライアル期間のA/Bテストを開始<br>・ユーザーインタビューを実施し、定性的なフィードバックを収集 | ・KPIダッシュボード<br>・ユーザーインタビュー議事録 |

---

## Phase 4: 改善と拡大 (17週目〜)

**目的:** Phase3で得られたデータとインサイトに基づき、プロダクトとマーケティング戦略を継続的に改善し、事業を成長軌道に乗せる。
**担当領域:** 全員
**成功指標(KPI):**
*   **MRR（月間経常収益）: 50万円達成**
*   有料会員数: 1,000人達成
*   アプリストア評価: 4.5以上

| 週 | 主要タスク | 具体的なアクション | 完了成果物 |
| :--- | :--- | :--- | :--- |
| **17-20** | **MVP改善サイクル** | ・ユーザーフィードバックに基づき、改善タスクの優先順位を決定<br>・AIコーチの応答品質改善、オンボーディングの最適化など、2週間スプリントで改善を繰り返す | ・改善タスクバックログ<br>・週次リリースノート |
| **21-24** | **機能拡張 (v1.1)** | ・ユーザーから要望の多かった「**匿名コミュニティ機能**」を開発・実装<br>・Todoist連携機能の開発に着手 | ・匿名コミュニティ機能<br>・Todoist連携機能プロトタイプ |
| **17〜** | **マーケティング拡大** | ・CVRが高かったチャネル（例: X）への広告出稿を開始<br>・ユーザーの成功事例を**noteの記事やXのポスト**としてコンテンツ化<br>・インフルエンサーマーケティングを本格化 | ・広告キャンペーンレポート<br>・ユーザー事例コンテンツ |

本ロードマップは、日本市場での成功確率を最大化するための計画です。市場の反応を注意深く観察し、常に学び、柔軟に計画を更新していくことが重要です。
