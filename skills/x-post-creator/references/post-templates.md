# X投稿テンプレート集

このドキュメントは、投稿案作成時に構成の参考にするためのテンプレートです。そのままコピーするのではなく、トピックに応じてアレンジしてください。

## パターンA：ノウハウ・インサイト型テンプレート

### テンプレートA-1：逆説型

```
[ターゲット]がやりがちな[行動]、実は逆効果かもしれません。

僕が[N社/N件]の[業種]を見てきて気づいたのは、

・[ポイント1]
・[ポイント2]
・[ポイント3]

大事なのは[核心メッセージ]。

[問いかけ]
```

### テンプレートA-2：数字インパクト型

```
[具体的な数字]。

これは[何の数字か]です。

[背景の説明を1-2行]

じゃあどうすればいいか？

[解決策を箇条書き3つ]

[問いかけ]
```

### テンプレートA-3：比較型

```
[A]と[B]、どっちが正解？

結論から言うと、[答え]。

理由は3つ：
①[理由1]
②[理由2]
③[理由3]

ただし[例外や補足]。

あなたの会社ではどちらを選びますか？
```

## パターンB：ストーリー・事例型テンプレート

### テンプレートB-1：ビフォーアフター型

```
[驚きの結果]になった話。

[クライアント/自分]は[以前の状態]だった。

[きっかけ]をきっかけに、[やったこと]を始めた。

結果：
・[成果1]
・[成果2]
・[成果3]

ポイントは[学び]だった。

同じような経験をした方いますか？
```

### テンプレートB-2：失敗談型

```
正直に言います。

[失敗した内容]をやらかしました。

[何が起きたか]

そこから学んだのは、
[教訓]

今は[改善後の状態]。

[問いかけ]
```

## パターンC：note記事の再構成型テンプレート

### テンプレートC-1：ユースケース切り出し型

```
[業種/業務]の[課題]、AIで解決できます。

例えば：
・[具体例1]
・[具体例2]
・[具体例3]

特に[ターゲット]にとっては[メリット]。

他にもこんな活用法があれば教えてください。

※詳しい解説はリプ欄のnoteで👇
```

### テンプレートC-2：図解プレビュー型

```
【図解】[テーマ]を整理しました。

[図解の概要を1-2行で説明]

ポイントは：
①[要点1]
②[要点2]
③[要点3]

全体像はnoteで詳しく解説しています。
（リンクはリプ欄に👇）

この中で一番気になるのはどれですか？
```

## 問いかけのバリエーション

投稿の最後に使える問いかけのバリエーションです。毎回同じにならないよう、ローテーションしてください。

| カテゴリ | 問いかけ例 |
|---|---|
| 経験共有 | 「同じ経験をした方いますか？」 |
| 意見募集 | 「あなたはどう思いますか？」 |
| 二択 | 「AとB、あなたならどちらを選びますか？」 |
| 具体化 | 「あなたの会社ではどうしていますか？」 |
| 追加情報 | 「他にもこんな方法があれば教えてください」 |
| 共感確認 | 「これ、あるあるだと思いませんか？」 |
| 優先順位 | 「この中で一番大事だと思うのはどれですか？」 |
