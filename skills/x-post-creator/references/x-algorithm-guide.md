## 1. エンゲージメントスコアリングの仕組み

Xの「For You」フィードは、ユーザーがフィードを開くたびに以下のパイプラインを実行します。

1. **候補の収集**: フォロー中のアカウント（In-Network）とフォロー外のアカウント（Out-of-Network）から投稿を収集
2. **情報の付加**: 各投稿にエンゲージメント数、動画長さなどのメタデータを付加
3. **フィルタリング**: ブロック、ミュート、キーワードミュート、既読、古すぎる投稿を除外
4. **スコアリング**: 残った投稿に対し、各ユーザーごとに「この人がこの投稿にどう反応するか」を予測し、スコアを算出
5. **トップ選出**: 最高スコアの投稿だけが表示される（ハードカットオフ）

重要なのは、スコアは「投稿の質」ではなく「特定のユーザーがその投稿に反応する確率」で決まるという点です。

## 2. エンゲージメントアクションの重み（推定）

正確な重みは非公開ですが、以下の順で重要度が高いと推定されます。

| アクション | 推定重要度 | 理由 |
|---|---|---|
| フォロー獲得 | 最高 | 投稿を見て新規フォローは最強のシグナル |
| リプライ | 非常に高い | 思考と入力の手間がかかる高コストアクション |
| シェア/DM共有 | 非常に高い | 自分の評判をかけて他者に推薦する行為 |
| 引用ツイート | 高い | 自分のコメントを付加する投資行動 |
| リポスト | 中程度 | ワンクリックだが拡散意思の表明 |
| いいね | 低〜中程度 | 最もコストが低いアクション |
| ネガティブ（非表示/ミュート/ブロック） | 大幅なマイナス | スコアを著しく下げる |

## 3. フィルタリングで落とされるパターン

以下の条件に該当する投稿は、スコアリング以前にフィルタリングで除外されます。

- **ミュートキーワード**: 多くのユーザーがミュートしている政治的・炎上系のキーワードを含む投稿
- **重複コンテンツ**: 同一または類似の内容を繰り返し投稿した場合
- **古すぎる投稿**: 一定時間（推定数時間〜半日）を超えた投稿はハードカットオフ
- **外部リンク**: 外部URLを含む投稿はリーチが制限される傾向がある（Xプラットフォーム外への離脱を防ぐため）

## 4. 投稿タイミングの最適化

BtoBターゲット（中小企業経営者・マーケター）向けの最適な投稿時間帯は以下の通りです。

| 時間帯 | 推奨度 | 理由 |
|---|---|---|
| 平日 7:00-8:00 | 高い | 通勤時間帯、情報収集タイム |
| 平日 12:00-13:00 | 高い | 昼休み、SNSチェックのピーク |
| 平日 18:00-20:00 | 中程度 | 帰宅後のリラックスタイム |
| 土日 | 低い | BtoBターゲットはビジネスモードではない |

早期エンゲージメント（投稿後1-2時間以内）が全てを決めるため、フォロワーがアクティブな時間帯に投稿することが極めて重要です。

## 5. 伸びる投稿の構成パターン

### 三段階構成（共感→価値→行動）
1. **共感**: 読者の悩みや課題を提示し、「わかる」と思わせる
2. **価値**: 解決策やインサイトを提供する
3. **行動**: 問いかけやCTAで次のアクションを促す

### フックの書き方
- 最初の1行で「誰に」「何を」伝えるかを明確にする
- 具体的な数字を入れる（「売上が2倍に」「3つの方法」）
- 反直感的な主張で注意を引く（「〇〇は逆効果」）
- ターゲットを名指しする（「中小企業の経営者へ」）

### 問いかけの例
- 「あなたの会社ではどうしていますか？」
- 「AとB、どちらが効果的だと思いますか？」
- 「同じ経験をした方いますか？」
- 「他にもこんな活用法があれば教えてください」

## 6. Author Diversity（投稿間隔）

Xのアルゴリズムは、同一著者の投稿が1人のフィードに連続して表示されることを制限します。そのため、重要な投稿は時間を空けて投稿することが推奨されます。1日2-3投稿が適切で、最低でも3-4時間の間隔を空けてください。
