# X Post Creator for Ryota Hashimoto

このスキルは、橋本良太氏（@RyotaHashi95551）のX（旧Twitter）アカウント向けに、アルゴリズムに最適化された高品質な投稿案を一度に3件作成するためのものです。

## ターゲットオーディエンスと専門領域

橋本氏の専門領域は「AI活用（特にManusなどのAIエージェント）」「BtoBマーケティング」「中小企業の売上アップ」です。ターゲットとなる読者は、主に中小企業の経営者やBtoBマーケターであり、彼らが抱える課題（人手不足、属人化、リード獲得の伸び悩みなど）に対する解決策を提示します。

トーン＆マナーは「カジュアル寄り」でありながら、「AI活用×BtoBマーケの専門家」としての信頼感とポジショニングを確立するものを目指してください。

## 投稿作成のワークフロー

以下のステップに従って、3件の投稿案を作成してください。

### 1. リサーチとトピック選定
まず、ターゲット層に刺さる最新のトピックや、X上のトレンドを調査します。
- 中小企業経営者が直面しているリアルな課題（例：採用難、業務効率化の限界）
- BtoBマーケティングの最新トレンドやAIツールの活用事例（例：Manusを使った業務自動化）
- 橋本氏の過去のnote記事（例：「Manusで変わった仕事の中身」「コードを書けない経営者が、1日でアプリを出した方法」など）からのインサイト抽出

### 2. 投稿案の構成（3パターン）
1回の実行で、必ず以下の異なるアプローチを持つ3件の投稿案を作成してください。

**パターンA：ノウハウ・インサイト型**
BtoBマーケティングやAI活用に関する具体的なノウハウや、反直感的なインサイトを提供する投稿。
- 構成：「共感（課題の提示） → 価値（解決策・インサイト） → 行動（問いかけ）」

**パターンB：ストーリー・事例型**
中小企業の経営者との伴走経験や、自身のキャリア（不動産→運送屋→アパレル→製造業→AI翻訳→独立）に基づくリアルなエピソードを交えた投稿。
- 構成：「フック（驚きのある書き出し） → ストーリー展開 → 学び・教訓」

**パターンC：note記事の再構成型（図解・ユースケース）**
橋本氏のnote記事（例：「Manusで中小企業の業務を自動化する10のユースケース」など）から1つの具体的なユースケースや図解のアイデアを切り出し、X向けに短く再構成した投稿。
- 構成：「結論（〇〇ができる） → 具体例（箇条書き） → 詳細への誘導（自己リプライ）」

### 3. Xアルゴリズム最適化ルールの適用
すべての投稿案において、以下の2026年版Xアルゴリズム最適化ルールを厳格に適用してください。

- **フックの強化**: 最初の1行（140文字以内）でトピックとターゲットを明確にし、「続きを読む」をクリックさせる工夫をすること。
- **エンゲージメントの促進**: 投稿の最後には必ず、読者がリプライしやすい「問いかけ」や「二択の質問（AとBどっち？）」を入れること。リプライはアルゴリズム上で最も高く評価されます。
- **リンクペナルティの回避**: 投稿本文（1ツイート目）には絶対に外部リンク（noteのURLなど）を含めないこと。リンクは「※リンクはリプ欄に貼ります」といった案内にとどめ、自己リプライ用のテキストとして別途作成すること。
- **視覚要素の推奨**: 各投稿案には、どのような画像や図解を添付すべきかの具体的なメモ（プロンプトや構成案）を添えること。画像付き投稿はエンゲージメントを高めます。
- **自己完結型**: スレッド形式にする場合でも、1ツイート目はそれ単体で価値が伝わり、シェア（リポスト）したくなる内容にすること。
